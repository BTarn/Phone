# Fossify Phone (Customized Fork)

<img alt="Logo" src="graphics/icon.webp" width="120" />

This repository is a modified version of the **[Fossify Phone](https://github.com/FossifyOrg/Phone)** app. It maintains the core philosophy of a private, ad-free, and open-source calling experience while introducing specific UX adjustments for a more streamlined workflow.

> [!NOTE]  
> This is a personal fork and is not officially affiliated with or endorsed by the Fossify organization. I am maintaining this version independently to implement specific features that do not align with upstream contribution guidelines.

## 🛠 Key Modifications

Unlike the standard version, this fork includes the following changes:

1.  **Unified Navigation:** The **Favorites** and **Contacts** tabs have been merged into a single view for quicker access.
2.  **Dialer Selection Fix:** Improved logic when selecting a contact name from the dialer; the app now correctly initiates the call to the associated number even after partial number entry.
3.  **Persistent Metadata:** The "Number Type" (e.g., Mobile, Work, Home) is now forced to always display within the **Recent Calls** list for better context at a glance.

## 🚀 About Fossify Phone

Fossify Phone is designed for seamless and secure everyday communication, free from ads and intrusive permissions.

* **Privacy First:** Your data stays on your device. 
* **Open Source:** Built on a transparent foundation that respects user freedom.
* **Efficiency:** Lightweight design optimized for low battery drain and smooth performance.
